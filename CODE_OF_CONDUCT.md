# Code of Conduct

This project follows the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## Summary

- Be respectful, constructive, and professional.
- Disagree about ideas, not about people.
- No harassment, no discrimination, no personal attacks.
- Report unacceptable behavior to **admin@dominusaxis.com**.

## Enforcement

The maintainer will review reports and take action proportional to the severity of the behavior, including warnings, temporary bans, or permanent bans from the project.
